# Security Policy

## Supported Versions

TopoGlyph is pre-1.0; only the latest published `0.x` release is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |
| < 0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in TopoGlyph, please do not open a public issue. Instead, report it via email to the project maintainers. We aim to respond within 48 hours to coordinate a security fix and release path.
